# 4/3/2 Recorder

スピーキング練習の **4/3/2 テクニック**（同じ話を 4 分 → 3 分 → 2 分で繰り返す）を、
タイマー・録音・メモをひとつにまとめて回すためのウェブアプリです。

ブラウザだけで動きます。インストール不要、サーバー不要、録音は端末の外に出ません。

## モードは 2 つ

| モード | 進行 | 狙い |
| --- | --- | --- |
| **4/3/2**（既定） | 4分 → 休憩 → 3分 → 休憩 → 2分 | 同じ話を削りながら速くする。時間の圧で自動化する |
| **ひとりで話す** | 型に当てる1分 → 構える → 1回目1分 → 聞き返す1分 → 言い直す1分 → 構える → 2回目1分（計 5分6秒） | 相手なしで組み立てる。自分の録音を聞き手の代わりに立てる |

準備画面の一番上で選びます。選んだモードは次に開いたときも残ります。

**「ひとりで話す」で変えていること**

- **残り10秒のカウント音を鳴らしません。** 1分のうち10秒は、話の締め（自分はどう思うか）に重なります
- **録音の前に3秒の「構える」を挟みます。** 時計はマイクの起動を待たずに動き出すので、この3秒がないと話し始めが削られます
- **マイクの自動ゲイン・ノイズ抑制・エコー除去を切ります。** 自動ゲインは小声を持ち上げ、ノイズ抑制は沈黙を作り直してしまいます。「どこで止まったか」を見る録音では、どちらも消してはいけないものを消します
- **文字起こしは出しません。** 1分 → 1分では words/min が語数と同じ意味になり、見たいもの（組み立て）ではなく速さの側を映します

### ①で何を話すか

この 3 つを順に当てるだけです。内容を考えるのに時間を使いません。

```
ⓐ 何の話だったか
ⓑ 誰が、何をしたか
ⓒ 自分はどう思うか
```

言葉が出てこない所は飛ばして進みます。うまく話すことは目的ではなく、1 分を埋めて 2 回目を少し良くするのが目的です。

## 使い方

1. **話題を一つ決める** — 慣れた内容にすること（話したい内容など）
2. **メモは 3〜4 単語まで** — 原稿は書かない。入れた単語はラウンド中も画面に出ます
3. **スタート** — あとは画面の進行に従うだけ

| フェーズ | 画面に出ること |
| --- | --- |
| 1ラウンド目 4分 | 内容を出し切る。詰まって ok。沈黙 ok。 |
| 休憩 1分 | 言えなかった単語を 1〜2 個メモして調べる（その場で入力＆検索リンク） |
| 2ラウンド目 3分 | 同じ内容を、無駄に削って言う |
| 休憩 1分 | 何も見ない。深呼吸だけ（メモも指示も画面から消えます） |
| 3ラウンド目 2分 | 早く多少雑でも止まらないこと |

終わると 3 ラウンド分の録音がその場で聴き返せます。
各ラウンドの音声は個別に保存でき、セッションは履歴に残ります。

## できること

- 4 分 / 1 分 / 3 分 / 1 分 / 2 分の自動進行（時間は設定で変更可、`4 / 3 / 2` に戻すボタンあり）
- ラウンドごとの自動録音と、その場での再生・ダウンロード
- 残り 10 秒のカウント音とラウンド終了のチャイム（オフ可）
- 入力レベルのメーター、録音中インジケーター、画面スリープの抑止
- 休憩 1 の「言えなかった単語」メモと検索リンク、休憩 2 の呼吸ガイド
- 履歴（端末内の IndexedDB に保存。録音も含めて再生できます）
- **書き出し・読み込み** — セッションを音声ごと 1 つのファイルにまとめて保存でき、
  別の端末やブラウザで読み込むと履歴に戻ります。バックアップと持ち運びの両方に使えます
- **文字起こし（任意・ベータ）** — 端末の音声認識を使い、ラウンドごとの語数と
  words/min を出します。同じ内容を 4 → 3 → 2 分で話すので、速度の変化が数字で見えます。
  対応していない端末では自動でオフになります。
- ホーム画面に追加すればアプリのように起動でき、オフラインでも動きます
- ラウンドが終わるたびに保存されるので、途中でアプリが落ちても、それまでの録音は
  履歴に「途中まで」として残ります（自分で中断したときは残しません）

## 動かす

マイクを使うため **https か localhost** で開く必要があります（`file://` では録音できません）。

```bash
# このディレクトリで
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

iPhone で使うなら GitHub Pages などに置くのが手軽です
（リポジトリの Settings → Pages → Branch: `main` / `(root)`）。
公開後、Safari で開いて「ホーム画面に追加」すると全画面で使えます。

## テスト

実ブラウザ（Chromium）で通しの操作・自動進行・休憩の挙動を確認します。

```bash
npm install      # playwright（テスト用。アプリ本体に依存はありません）
npx playwright install chromium
npm test
```

- `tests/flow.test.mjs` — 準備 → 3 ラウンド録音 → 結果 → 履歴 → 削除までの通し
- `tests/timing.test.mjs` — 時計を早送りして 4/3/2 が自分で回りきることを確認
- `tests/breaks.test.mjs` — 休憩の手動送りと呼吸ガイド
- `tests/transfer.test.mjs` — 3 ラウンド分の書き出し → 別環境で読み込み → 再生まで
- `tests/robustness.test.mjs` — ボタンの二度押し、途中で落ちたときの録音の残り方
- `tests/update.test.mjs` — 更新が 1 回の再読み込みで届くか、オフラインで起動できるか
- `tests/layout.test.mjs` — ボタンが画面の下端にそろうか（iOS のツールバー対策）
- `tests/modes.test.mjs` — 既定が 4/3/2 のままか、「ひとりで話す」が別の進行で回りきるか

## 対応ブラウザ

| 機能 | Safari (iOS 14.3+) | Chrome / Edge | Firefox |
| --- | --- | --- | --- |
| タイマー・進行 | ○ | ○ | ○ |
| 録音（MediaRecorder） | ○（m4a） | ○（webm） | ○（webm） |
| 文字起こし（Web Speech API） | △ 端末による | ○ | ✕（自動でオフ） |

録音できない環境でも、タイマーとメモとしてはそのまま使えます。

## 保存されるデータ

**このアプリは録音の保管場所ではありません。** 下の通りブラウザのデータが消えれば
録音も消えます。消えるときはオリジンごとなので、古い分だけでなく 1 本目も一緒に消えます。
長く残したい録音は、書き出すか端末の録音アプリに移してください。

- 録音・トピック・メモ・文字起こしは、その端末のブラウザ内（IndexedDB）だけに保存されます
- どこにも送信しません。アカウントも通信もありません
- 設定 →「すべての履歴を削除」でまとめて消せます
- ブラウザのデータを消すと録音も消えます。残したいセッションは
  結果画面の「ファイルに書き出す」（または履歴・設定の「すべて書き出す」）で保存し、
  「読み込む」で戻してください
- 書き出しファイルは JSON で、音声は base64 で中に入っています。1 セッションでおよそ 2〜3 MB です

## 構成

```
index.html              画面の骨組み（準備 / セッション / 結果 / 履歴 / 設定）
assets/styles.css       スタイル（ライト・ダークテーマ対応）
src/config.js           4/3/2 の設定・各ラウンドの指示・フェーズの組み立て
src/session.js          フェーズ進行と残り時間（絶対時刻ベースでズレない）
src/audio.js            マイク・ラウンドごとの録音・入力レベル・合図の音
src/speech.js           音声認識による文字起こし（任意）
src/storage.js          IndexedDB への保存
src/transfer.js         ファイルへの書き出し・読み込み
src/app.js              画面まわりの配線
sw.js                   オフライン用のキャッシュ
tests/                  実ブラウザでの動作確認
```
